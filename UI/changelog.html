RELEASE NOTES

Changelog

What changed in each Prism build. Downloads live on GitHub Releases.

0.1.3 · macOS

2026-10-26 · BETA

Fixed

  • The previous Mac beta (0.1.2) had a registration issue: email confirmation links pointed to localhost. The production redirect is corrected, and this version explicitly returns to the Prism website. Request a fresh confirmation email if your old link still points to localhost.

New

  • A guided first-video tutorial highlights Start creating and walks you through upload, settings, captions, and creation, followed by an optional editor tour.
  • Replay the tutorial from Settings → Account.

Download the fixed macOS beta. Contributor: NeoChief (@neochief).

v0.2.0-beta.2

2026-10-21 · BETA

New

  • Installers for macOS (.dmg), Windows (.exe) and Linux (.AppImage), built on every release tag.
  • Native Windows and Linux workspaces on a shared engine. Both are untested on real devices.

Fixed

  • Gemini timeouts now fail the run instead of silently dropping results.
  • Crops stay inside frames with odd pixel sizes.
  • macOS release builds with the newest Xcode and its own SQLite.

Earlier builds

2026-10-18 – 10-20

  • First Prism video-to-Shorts editor for Mac.
  • Gemini became the only AI pipeline for picking Shorts and framing.
  • Better Shorts selection, caption customization and editing.
  • Shared rendering engine with tests.
