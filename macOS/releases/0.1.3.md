# Prism 0.1.3 — macOS beta

**Registration fix: use this version instead of the previous macOS beta (0.1.2).** Registration in the previous release was affected by confirmation emails pointing to `localhost:3000`, preventing testers from finishing signup. The production Supabase redirect is corrected, and this app explicitly requests `https://prismclips.vercel.app/login`. If an old email still points to localhost, request a fresh confirmation email.

## Changes

- A first-login tutorial dims the app, highlights **Start creating**, and guides you through uploading a video, choosing Short settings, captions and content type, and creating your first Short.
- **You created your first video** appears after a successful generation. You can then choose an optional tour of the editor, captions, timeline and export controls.
- Tutorial completion is remembered per account on your Mac. Use **Finish later** to pause or **Settings → Account → Replay first-video tutorial** to start again.
- Includes the latest account usage controls: a 60-minute beta allowance, promo-code redemption, and server-side request and spend checks.

## Downloads

This release contains **macOS assets only**, for **macOS 14 or newer on Apple Silicon**.

- `Prism-macOS.dmg`: open the disk image and drag Prism to Applications.
- `Prism-0.1.3.zip`: the same app as a ZIP archive.
- `SHA256SUMS.txt`: checksums for both downloads.

This beta is locally code-signed and is **not Apple-notarized**. macOS may require you to approve opening it.

## Validation

The production build, strict code-signature verification, account regression tests, tutorial tests and existing Mac editor regression tests passed. The tutorial was checked in the native Mac UI, including spotlight clicks, scrolling, the optional editor tour and export dialog. The tutorial success state was checked with simulated generation; a fresh real-email confirmation and another live AI generation were not run for this release.
